# Музыкальный архив встречи одноклассников — 60 лет

## Один QR-код для всех 7 песен

**Музыкальный плеер со списком треков, кнопками ▶, ⏮ и ⏭:**

https://sakhayanchos-ux.github.io/60--/music.html

В нём можно выбрать любую песню, поставить на паузу, перемотать, перейти к предыдущей или следующей. После окончания композиции плеер старается автоматически воспроизвести следующую (в зависимости от настроек мобильного браузера).

В GitHub Pages нужно включить публикацию из ветки `main`, каталог `/(root)`.

## Файлы

В корне хранятся `video-1.mp4` — `video-5.mp4` и `audio-1.mp3` — `audio-7.mp3`. Музыкальная страница `music.html` использует именно эти MP3.

**Важно:** не переименовывайте MP4 и MP3 через кнопку редактирования текста файла в GitHub — это может повредить двоичное содержимое. Репозиторий публичный, доступ по ссылкам открыт всем.
